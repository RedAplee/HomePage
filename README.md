Homepage — a brief guide

Homepage is a personal start page where you can gather all the websites you need in one place.

🚀 Getting started

To open the site, double‑click the Index.html file; the site will automatically open in your browser.

On the first launch, enter your name. You can change it later in the Settings.

📁 Cells

Create cells for different categories: Studies, Games, Work, Utilities, etc.
Add the necessary websites inside.

🎨 Design

In the Settings, you can choose one of the available themes.

💾 Presets — saving

To save your Homepage:
Menu → Presets → Export JSON
A file with your name will be saved, for example:
Alex.json

It contains your cells, websites, and Homepage settings.

To restore Homepage:
Menu → Presets → JSON Import

If the file contains a different name, Homepage will ask whether to keep your name or replace it.

Tip: keep the JSON file separate — this is your Homepage backup.
